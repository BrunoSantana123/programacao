# NEXO — exclusão de conta
O recurso é separado da integração MCP e fica nas configurações do site oficial. A senha é revalidada pelo Supabase; a confirmação EXCLUIR é obrigatória. O servidor só remove o ID obtido do token e confirmado pela nova autenticação. Não recebe um ID de destino do navegador. A chave administrativa permanece no servidor.
## Implantação
Antes de mesclar/publicar o site, implantar a Edge Function nexo-delete-account em homologação com origens adequadas, e validar os fluxos usando duas contas descartáveis. Confirmar que as tabelas de usuário têm ON DELETE CASCADE, que nenhuma conta possui objetos Storage bloqueantes, que sessões anteriores não conseguem recriar os dados e que a conta B permanece intacta. Verificar tokens OAuth antigos, expiração, logs e retenção de backups; não afirmar apagamento instantâneo de backups. A versão inicial restringe a origem ao site oficial. Após testes e revisão, implantar a função em produção antes de habilitar o botão. Nunca testar exclusão em contas reais. Testes unitários: node --test tests/test-account-deletion.mjs.
