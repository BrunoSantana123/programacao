# Meus primeiros projetos em Python

Projetos de estudo feitos do zero.

- **gastos.py**: app de controle financeiro com menu, categorias e dados salvos em arquivo.
- **bot.py**: bot de atendimento que responde dúvidas e identifica leads quentes.

Para rodar: instale o Python e execute `python gastos.py` ou `python bot.py`.
